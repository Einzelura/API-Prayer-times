# Islamic Prayer Times & Spiritual App

## Overview
This web application helps users stay connected with their daily Islamic practices. It features:
- Accurate prayer times based on the user's location.
- A digital Tasbih counter for daily dhikr.
- Random Quranic Ayah with Arabic text and translation.
- Daily Hadith in Arabic and English.

## Features
1. **Prayer Times**
   - Shows Fajr, Sunrise, Dhuhr, Asr, Maghrib, and Isha.
   - Automatically updates countdown for next prayer.
   - Highlights the upcoming prayer visually.

2. **Digital Tasbih**
   - Five types of dhikr: Astaghfirullah, Subhan Allah, Alhamdulillah, La ilaha illallah, Allahu Akbar.
   - Click to count, double-click for color effect, reset with Clear button.

3. **Daily Quranic Ayah**
   - Displays random Ayah with Surah name.
   - Shows Arabic text and English translation.
   - Button to get a new Ayah.

4. **Daily Hadith**
   - Displays random Hadith from Sahih Bukhari or Sahih Muslim.
   - Arabic text and English translation.
   - Button to get a new Hadith.

## Installation
1. Clone or download the project.
2. Open `index.html` in any modern browser.
3. Make sure you have an internet connection to fetch prayer times, Quranic Ayah, and Hadith.

## Technologies
- HTML, CSS, JavaScript
- Aladhan API for prayer times
- AlQuran Cloud API for Ayahs
- Hadith API by Fawaz Ahmed

## Notes
- Geolocation may affect prayer time accuracy because it uses the user's IP address when GPS is not available.
- Fully responsive for desktops, tablets, and mobile devices.
